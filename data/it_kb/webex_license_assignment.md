## Symptoms

The user reports an issue related to Webex.

## First-line Troubleshooting

Verify department eligibility, manager approval, subscription seat limit, active seats, and renewal date. Current known issue: Webex has 42 active seats against 40-seat limit. Outdated note: older runbooks said add temporary seats and reconcile later; this is no longer valid.

## Required Ticket Fields

employee_id, email, system, business impact, error text, screenshot if safe, requested access level if applicable.

## Escalation

Escalate to IT Manager for admin access, over-limit subscriptions, security risk, or missing approvals. Related policies should be retrieved before final decision.
