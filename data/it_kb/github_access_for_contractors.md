# GitHub Access for Contractors

KB article ID: IT-KB-106
Last updated: 2026-06-20
Owner team: IT
Related systems: GitHub
Raw inspiration: Kaggle Synthetic IT-Related Knowledge Items, normalized for NovaOps.

## Symptoms

The user reports an issue related to GitHub.

## First-line Troubleshooting

Confirm contractor status, end date, SOW scope, manager approval, IT approval, named repositories, review date, MDM, and MFA. Contractor org admin access is not allowed.

## Required Ticket Fields

employee_id, email, system, business impact, error text, screenshot if safe, requested access level if applicable.

## Escalation

Escalate to IT Manager for admin access, over-limit subscriptions, security risk, or missing approvals. Related policies should be retrieved before final decision.
